mediainterface (Java 8 fork)

Public Maven repository for copyandexecute/mediainterface. No auth required.

Uber-JAR (one dependency, everything included)

repositories {
    maven("https://copyandexecute.github.io/mediainterface/")
}
dependencies {
    implementation("org.endlesssource.mediainterface:all:<VERSION>")
}

Contains core + windows (DLLs x64/arm64) + linux (MPRIS/DBus) + macos (framework) with SPI service files merged. slf4j-api is declared as an optional runtime dep (Minecraft already provides it).

Individual modules

implementation("org.endlesssource.mediainterface:core:<VERSION>")
implementation("org.endlesssource.mediainterface:windows:<VERSION>")
implementation("org.endlesssource.mediainterface:linux:<VERSION>")
implementation("org.endlesssource.mediainterface:macos:<VERSION>")

Versioning

YY.Q.BUILD-branch (e.g. 26.2.1-dev-java-8) or clean semver on tag push (v1.0.0 → 1.0.0).
